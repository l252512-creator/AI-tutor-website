# AI-TUTOR – Responsive Single-Page Website

## Seed Idea
AI-TUTOR is a fictional educational platform designed to help learners improve their skills using AI-powered guidance.  
The website is a fully responsive single-page interface showcasing the platform and an interactive user form — created entirely with **HTML5 + CSS3**.

---

## Design Rationale
The design emphasizes clarity, accessibility, and responsiveness:

- **CSS Grid** is used for the global page layout (header, hero, form, footer).  
- **Flexbox** is used inside components (navigation menu, form groups).  
- **Three responsive breakpoints** ensure smooth device compatibility:  
  - Mobile (0–767px)  
  - Tablet (768–1024px)  
  - Desktop (1025px+)  
- **Three CSS-only interactive components**:  
  1. Hover-animated navigation underline  
  2. Hover-zoom effect on form fields  
  3. Submit button hover and scale effect  
- Colors and typography were chosen for high readability and accessibility.

---

## Features & Requirements Mapping

###  Structural Requirements
- Semantic HTML tags: `<header>`, `<main>`, `<section>`, `<article>`, `<form>`, `<footer>`  
- CSS Grid for global structure  
- Flexbox for component alignment  
- Fully responsive for mobile, tablet, and desktop

###  Interactive Components (CSS-only)
- Navigation underline on hover  
- Form field hover animation  
- Submit button hover animation  

###  Smart Form Requirements
- Text inputs: Name, Email  
- 3 Checkboxes: Services (Personalized Learning, Adaptive Assessment, Predictive Analysis)  
- 3 Radio buttons: Plan Type (Weekly, Monthly, Yearly)  
- Select dropdown: Function (Humanizer, AI Detector, Grammar Correction)  
- Textarea: Feedback  
- Submit button with hover effect  
- Labels + keyboard focus for accessibility
